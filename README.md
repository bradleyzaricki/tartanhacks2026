# tartanhacks2026
Reprompted reduces wasted AI computation by reusing answers that already exist.
AI models are expensive to run and consume large amounts of energy and water.

When a user submits a prompt, Reprompted checks if the same or a similar question was asked before.
If a match is found, the cached response is returned instantly instead of calling the model again.

Prompts are normalized and compared using similarity vectors to catch equivalent questions.
Token savings are tracked and visualized through a simple, gamified system that rewards efficiency.
